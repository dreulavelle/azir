# Changelog

## [0.2.0](https://github.com/dreulavelle/azir/compare/v0.1.0...v0.2.0) (2026-09-03)


### ⚠ BREAKING CHANGES

* **security:** sealed credentials are now bound to their (plugin, kind, customer) scope as AES-GCM additional authenticated data, so a ciphertext copied into another row no longer opens. Credentials sealed before this cannot be read under the new rule and are deleted by migration 0024; affected integrations show as unconfigured until an administrator enters them again.
* SQLite is replaced by Postgres. DATABASE_URL is now required and AZIR_DB_PATH is gone. Nothing is migrated; no real data existed.
* Postgres is replaced by SQLite and the five-container deployment collapses to one. Nothing is migrated; the prior stack held no real data.
